# M5Core 闹钟

面向 M5Stack Core 一代的屏幕闹钟项目。硬件主控与“FMO 伴侣屏 ESP32”相同，第一版用 PlatformIO + Arduino `M5Stack` 库实现，方便快速刷机验证。

## 功能

- 屏幕采用运动秒表式简化 UI：上方模式状态，中间大数字 LCD，底部 A/B/C 三键标签
- 主页按 A/MODE 在 `Time / Alarm / Stopwatch / Countdown / Pomodoro / WiFi / Rotate` 之间切换，不再保留表盘模式
- A/B/C 三个正面按键操作
- 5 组闹钟时间，可分别开关
- 所有闹钟固定使用你提供的内置音乐，可在编辑页预览
- 内置秒表、倒计时、番茄钟、WiFi/NTP 状态和 180 度屏幕旋转
- 开机最多等待 WiFi 约 6 秒，连不上会离线进入主界面，不会卡在连接页
- WiFi 页面支持扫描附近网络，并可启动 `M5Core-Alarm` 配网门户添加/更换 WiFi
- 通过互联网 NTP 自动校时，默认中国时区 UTC+8
- 闹钟配置保存到 ESP32 NVS
- 到点使用内置喇叭响铃
- 响铃时按任意键停止，60 秒无人操作自动停止

## 首次配网与校时

开机后会尝试连接已保存的 WiFi，约 6 秒后离线进入主页。需要配网时，进入 WiFi 模式按 C 开启配网热点：

- 热点名：`M5Core-Alarm`
- 手机或电脑连接这个热点后，按页面提示选择家里的 WiFi
- 配网成功后会自动使用 `ntp.aliyun.com`、`cn.pool.ntp.org`、`pool.ntp.org` 校时

## 按键

| 场景 | Button A | Button B | Button C |
| --- | --- | --- | --- |
| 主页 | MODE 切换模式 | 确认进入/执行 | 设置/进入当前模式 |
| 闹钟列表 | 上一项 | 确认当前项 | 下一项 |
| 编辑闹钟 | 切换字段 | 加一/执行 | 减一/跳过预览/完成返回 |
| 音乐预览 | 返回编辑 | 确认返回 | 重播音乐 |
| 秒表 | 回主页 | 开始/暂停 | 清零 |
| 倒计时 | 回主页 | 开始/暂停 | 运行中复位，暂停时 +1 分钟 |
| 番茄钟 | 回主页 | 开始/暂停 | 跳到下一阶段 |
| WiFi 状态 | 回主页 | 扫描网络 | 启动配网门户 |
| WiFi 扫描 | 上一项 | 选中/添加 | 下一项 |
| Rotate 模式 | 切换到下个模式 | 切换 0/180 度 | 切换 0/180 度 |
| 正在响铃 | 停止 | 停止 | 停止 |

编辑字段顺序：

1. 小时
2. 分钟
3. 音乐预览
4. 是否启用
5. 完成返回

闹钟列表和 WiFi 扫描都包含 `Back` 项，选中后按中间键回到上一级；秒表、倒计时、番茄钟和 WiFi 页按左键回主页。

## 构建与刷机

```bash
pio run
pio run -t upload
pio device monitor -b 115200
```

如果电脑还没有 PlatformIO，可以先安装：

```bash
python3 -m pip install platformio
```

## 本地模拟器

可以先在电脑浏览器里模拟 M5Core 320x240 屏幕和 A/B/C 三键交互：

```bash
python3 -m http.server 8766
```

然后打开：

```text
http://127.0.0.1:8766/tools/m5core-alarm-simulator/
```

模拟器覆盖秒表式主页、闹钟列表/编辑、音乐预览、秒表、倒计时、番茄钟、WiFi 扫描/添加提示和 WiFi/NTP 状态页。键盘 `A/B/C`、方向键和页面上的三个圆形按钮都可以操作。

## 硬件说明

M5Stack Core 一代常用资源：

- LCD：320x240，横屏使用
- Button A/B/C：GPIO 39 / 38 / 37，低电平按下
- 内置喇叭：ESP32 DAC GPIO25
- 背光、LCD SPI、TF 卡等引脚与 FMO 伴侣屏项目保持同一类 M5Core 假设

## 内置音乐

你提供的 `lv_0_20260701194630.mp3` 已保存在 `assets/builtin_alarm_music.mp3`，固件内置版位于 `src/music_builtin.h`。

固件使用 `huge_app.csv` 分区方案，把完整 MP3 转换为 8kHz、单声道、8-bit PCM 内置到程序中。当前播放速率为 9600Hz，约比原曲快 20%，完整音乐可播放约 50 秒。
